# Buku Tamu Digital — BKPSDM Kota Cirebon (Demo Portofolio)

Versi statis (HTML + JavaScript) dari aplikasi Buku Tamu Digital. Data disimpan di browser (localStorage).

Admin demo: `admin@example.com` / `admin123`

## Deploy di GitHub Pages
1. Buat repository baru di GitHub, unggah isi folder ini (index.html di root).
2. Settings > Pages > Source: Deploy from a branch > main / (root) > Save.
3. Situs aktif di https://USERNAME.github.io/NAMA-REPO/
